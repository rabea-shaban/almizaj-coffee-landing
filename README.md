## 🌟 Project Overview

**Qahwat Al Mizaj** is a premium landing page built for a Saudi coffee shop brand. The site features a modern Arabic RTL layout, polished visuals, and a responsive UI designed to evoke the premium feel of the brand. It presents the coffee shop story, menu highlights, customer testimonials, and an Instagram-style gallery.

---

## ✨ Features

- Fully responsive design for desktop, tablet, and mobile
- Arabic RTL support with elegant typography and layout
- Hero section with brand imagery and messaging
- Menu showcase with featured coffee items
- About section highlighting brand story
- Testimonials section with customer feedback
- Instagram gallery section for visual storytelling
- Reusable React components for maintainability
- Optimized performance with Vite and Tailwind CSS

---

## 🧰 Tech Stack

- React.js
- TypeScript
- Tailwind CSS
- Vite

## 🚀 Installation & Setup

```bash
# Clone the repository
git clone https://github.com/rabea-shaban/qahwat-al-mizaj.git
cd qahwat-al-mizaj

# Install dependencies
npm install

# Run locally
npm run dev
```

Open the local development URL shown in the terminal to preview the site.
